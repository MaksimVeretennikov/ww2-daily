# Рубрика «Двумя глазами»

Одно событие этих дней 85 лет назад — как его фиксировали и подавали **две
стороны**. Используем наш мультиисточник (ru.wikipedia «Хроника ВОВ», дневник
Гальдера, onwar, en.wikipedia). Работай автономно.

## Процедура

### Шаг 0. Подготовка
```bash
pip install -r requirements.txt
```

### Шаг 1. Собрать факты
```bash
python scripts/fetch_sources.py
```
Прочитай `run/facts.json`: `date`, `combined` (особенно полезно сравнить
советские и немецкие/западные источники), `recent_posts`.

### Шаг 2. Выбрать событие и написать пост
Выбери одно событие этих дней, по которому стороны расходятся в оценке/подаче.
Напиши:
- `post`: короткий заголовок жирным (событие/место), пустая строка, затем два
  взгляда — например «С советской стороны: …» и «С немецкой стороны: …» — и
  короткий вывод, где правда или в чём расхождение. ~750–900 знаков. Без эмодзи,
  CAPS, ссылок. Будь аккуратен и честен: не приписывай источникам того, чего нет.
- `photo_caption` — подпись к фото, до ~150 знаков.
- `image_prompt` / `category_prompt` — связанный архивный кадр события.

### Шаг 3. Фото
```bash
python scripts/find_photo.py --image-prompt "<image_prompt>" --category-prompt "<category_prompt>"
```
**Посмотри превью (Read)**, выбери подходящий; нет — `image_index: -1`.

### Шаг 4. Опубликовать
`run/draft.json`:
```json
{ "kind": "perspectives", "ww2_date": "<facts.date.iso>",
  "topic": "<кратко по-английски>", "image_index": 0,
  "telegram_caption": "<i>{photo_caption}</i>\n\n<b>{заголовок}</b>\n\n{post}…",
  "post_x": "" }
```
Длину ≤ 1024. Затем `python scripts/publish.py`.

### Шаг 5. Сохранить память
```bash
git add state/history.json && git commit -m "rubric/perspectives: {topic}" && git push origin HEAD:main
```

## Правила
- **Без забеганий вперёд (дневник во времени):** только то, что известно к этой
  дате; без послезнания и будущего исхода («как мы знаем, позже…»).
- Честный, спокойный тон; обе стороны — без пропаганды, по фактам источников.
- Если `publish.py` пишет, что рубрика за сегодня уже была — НЕ форсируй, заверши.
- Бундесархив-фото → дисклеймер первой строкой, лимит 1024.
