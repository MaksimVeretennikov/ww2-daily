# Рубрика «Документ / Дневник»

Один реальный первоисточник этих дней ровно 85 лет назад — и его разбор.
Приоритет — Восточный фронт. Работай автономно.

## Процедура

### Шаг 0. Подготовка
```bash
pip install -r requirements.txt
```

### Шаг 1. Собрать факты
```bash
python scripts/fetch_sources.py
```
Прочитай `run/facts.json`: `date`, `combined` (события дней; источник
`Хроника ВОВ` и записи Гальдера особенно полезны), `recent_posts` (не повторяй
недавние темы).

### Шаг 2. Выбрать документ и написать пост
Выбери реальный документ этих дней: приказ/директиву, сводку Совинформбюро,
запись из дневника Гальдера, листовку, полосу газеты. Напиши:
- `post` на русском: короткий заголовок жирным (`<b>Документ: …</b>` или дата),
  пустая строка, **точная суть/цитата** документа (без выдумок — если точная
  формулировка неизвестна, передай смысл осторожно), затем контекст и значение.
  ~700–850 знаков. Без эмодзи, CAPS, ссылок.
- `photo_caption` — подпись к фото, до ~150 знаков.
- `image_prompt` / `category_prompt` — скан документа или связанный архивный кадр.

### Шаг 3. Фото
```bash
python scripts/find_photo.py --image-prompt "<image_prompt>" --category-prompt "<category_prompt>"
```
**Посмотри превью (Read)**, выбери подходящий архивный кадр. Не нашёл —
расширь запрос (1–2 повтора); `image_index: -1` только как крайний случай.

### Шаг 4. Опубликовать
`run/draft.json`:
```json
{ "kind": "document", "ww2_date": "<facts.date.iso>",
  "topic": "<кратко по-английски>", "image_index": 0,
  "telegram_caption": "<i>{photo_caption}</i>\n\n<b>{заголовок}</b>\n\n{post}…",
  "post_x": "<= 260, английский, та же тема, с даты (June D, 1941 —); без ссылок/эмодзи>" }
```
Длину `telegram_caption` держи ≤ 1024. Затем `python scripts/publish.py`.

### Шаг 5. Сохранить память
```bash
git add state/history.json && git commit -m "rubric/document: {topic}" && git push origin HEAD:main
```

## Правила
- **Без забеганий вперёд (дневник во времени):** документ и его трактовка — по
  состоянию на эту дату; не комментируй с позиции будущего исхода.
- Если `publish.py` пишет, что документ за сегодня уже есть — НЕ форсируй, заверши.
- Фактическая точность критична: не приписывай документу слов, которых не было.
- Бундесархив-фото → дисклеймер первой строкой (см. `daily-post`), лимит 1024.
