# Короткий ролик (VK Клипы / YouTube Shorts)

Собираешь динамичный вертикальный ролик в стиле популярных исторических
Shorts: **быстрая нарезка** (много кадров, короткие склейки) + **субтитры,
которые проговаривает голос** и появляются с лёгким наездом (pop-in) в
нижней-центральной части экрана. Делаешь **две версии — русскую и английскую**.
Работай автономно.

**Хронометраж:** жёсткий потолок 30 секунд, оптимум **~25 секунд** — этого
хватает на чуть более полную историю. Темп быстрый (поколение TikTok/Shorts):
короткие фразы, минимум пауз, постоянная смена кадров.

## Принцип дневника
Целевая дата — сегодня минус 85 лет. Всё в ролике — только то, что известно к
этой дате (правило «без забеганий вперёд»). Фактическая точность критична.

## Модель: фразы и кадры
- **`lines`** — закадровый текст короткими фразами. Каждая фраза одновременно
  **озвучивается и показывается субтитром** (аккуратная плашка с поп-ином в
  нижней-центральной зоне). Это смысловая дорожка.
- У каждой фразы — свой список **`shots`** (1–3 кадра). Кадр меняется ровно на
  новой фразе, а если у фразы несколько кадров — внутри неё идут быстрые
  доп-склейки. Так картинка всегда по смыслу совпадает с тем, что говорит
  голос, и при этом нарезка быстрая (всего ≈10–13 кадров на ролик).
Движок озвучивает фразы, раскладывает субтитры по времени речи и нарезает
кадры каждой фразы в её окно. (Можно дать и плоский `shots` на весь ролик —
тогда кадры просто равномерно распределятся, без смысловой привязки.)

## Кадрирование (важно)
- **Вертикальное/портретное фото** → заполняет весь кадр с медленным зумом.
- **Горизонтальное/квадратное фото или документ** → показывается **целиком,
  по центру, на собственном красиво размытом и затемнённом фоне** (никаких
  жёстких обрезок и пустых чёрных полей). Субтитр лежит в нижней-центральной
  зоне — туда смотрит глаз, поля сверху/снизу не мешают.

## Процедура

### Шаг 0. Зависимости
```bash
pip install -r requirements.txt -r requirements-video.txt
```

### Шаг 1. Факты и кадры
```bash
python scripts/fetch_sources.py
python scripts/find_photo.py --image-prompt "<запрос>" --category-prompt "<категория>"
```
**Посмотри превью (Read)** и отбери **10–13 сильных архивных кадров** по теме
(их `image_url` из `run/candidates.json`, либо локальные пути из пула). Бери
разные планы: лица, техника, командиры, карта/документ, общий план — это даёт
ритм при быстрой нарезке. Узнаваемый, сильный кадр — в финал.

### Шаг 2. Написать сценарий (RU + EN)
- **8–10 коротких фраз** (`lines`). Зацеп в первой фразе. **Темп быстрый.**
- Фразы — **законченные предложения для ЧТЕНИЯ ВСЛУХ**, а не телеграфные
  обрывки. Конструкции вида «Перебежчик: удар на рассвете» нормально читаются
  глазами, но звучат странно в озвучке — пиши «Перебежчик предупреждает о
  вторжении на рассвете». Проговори фразу про себя: звучит естественно?
- Каждая фраза короткая (1–2 строки), цепляющая, без эмодзи.
- **Не проси подписку и не добавляй призывы** в конце — финал бьёт смыслом.
- Если в тексте есть цифры/дата, добавь `say` для естественного произношения
  (`text`: «21 июня 1941», `say`: «двадцать первое июня сорок первого»).
- EN — самостоятельная версия, естественная (не дословный перевод).
- Целься в **~25 секунд** озвучки (потолок 30). Сверь Шагом 3a.

### Шаг 3. Записать `run/video_spec.json`
```json
{
  "ru": {
    "lines": [
      {"text": "21 июня 1941.", "say": "Двадцать первое июня сорок первого.",
       "shots": [{"image": "run/pool/p_10.jpg"}]},
      {"text": "Три группы армий — у самой границы.",
       "shots": [{"image_url": "https://…"}, {"image": "run/pool/p_15.jpg"}]},
      {"text": "До вторжения — считанные часы.",
       "shots": [{"image": "run/pool/p_01.jpg"},
                 {"video": "run/footage/clip.mp4", "start": 3.0}]}
    ]
  },
  "en": { "lines": [...] }
}
```
Каждый кадр — `image`/`image_url` или `video`/`video_url` (короткий архивный
клип, cover-fit; см. ниже). Сильной/финальной фразе можно дать 2 кадра, чтобы
она дольше держалась и «дышала».

### Шаг 3a. Проверить хронометраж (быстро, без рендера)
Синтезируй только `say`/`text` строк и сложи длительности — целься в **~25 с**
(потолок 30). Если перебор — подрежь/выкинь фразу.

### Шаг 4. Собрать ролики
```bash
python scripts/make_video.py
```
→ `run/video_ru.mp4`, `run/video_en.mp4` (1080×1920). Голос — edge-tts (за
SSL-прокси сам берёт системный CA-бандл; нет сети → ролик без голоса), музыка —
из `assets/music/` (слышимая пэд-подложка в среднем регистре).
**Проверь результат:** вытащи 4–6 кадров (`ffmpeg -ss <t> -frames:v 1`) и
посмотри (Read) — заполнение/размытие, читаемость субтитров, темп.

### Шаг 5. Публикация
Аплоадеры VK Клипов и YouTube Shorts — отдельно (нужны доступы), см. README.
Русский → VK Клипы, английский → YouTube Shorts.

## Архивное видео (для живости)
Подмешивай 2–3 коротких (≈2–3 с) клипа настоящей кинохроники — движение
оживляет ролик. Рабочий способ:
1. **Источник — общественное достояние.** Надёжный вариант: серия US War Dept.
   «Why We Fight» на Internet Archive (PD). Для вторжения 22 июня 1941 —
   `wwf_the_battle_of_russia_pt1` (Part 1, лето 1941); есть дериватив **720×540**
   (`the_battle_of_russia_pt1.mp4`), бери его, а не 320p. Universal Newsreels
   (коллекция `universal_newsreels`) — тоже PD и часто прямо по дате.
2. **Скачивание.** Статический ffmpeg тут не умеет seek по сети (segfault), а
   открытый поток крупного файла отваливается по таймауту — качай **чанками по
   32 МБ через HTTP Range** (см. приём в истории). metadata-API archive.org
   иногда отдаёт `error: unable to load metadata` (временный сбой узла) —
   пробуй альтернативные id того же фильма.
3. **Отбор — глазами.** Сделай контактные листы (`ffmpeg -vf
   "fps=1/15,scale=240:180,tile=8x6"`), посмотри (Read), найди нужный раздел
   (избегай карт, титров, чужого периода — напр. зимы 1941/42 для «кануна»).
   Уточни в окне детальным листом, вытащи кадры-кандидаты в полном разрешении,
   проверь **непрерывность** плана (3 кадра start/mid/end) — чтобы внутри клипа
   не было склейки.
4. **Нарезка.** `ffmpeg -ss <t> -t <2.5..3> -i film.mp4 -an -c:v libx264
   -pix_fmt yuv420p clip.mp4` (перекодировка убирает артефакты, звук не нужен).
5. **В спеке** — `{"video": "run/footage/clip.mp4"}` в `shots` нужной фразы.
   Движок впишет клип целиком по центру на размытом фоне (низкое разрешение не
   растягивается на весь кадр). Видео-кадр держи коротким и в паре с фото, чтобы
   не вылезти за непрерывный план.
Историческая точность обязательна и для видео: бери кадры именно того периода.

## Качество
- Кадры — архивные, той эпохи; де-дубликация фото общая (по `pageid`).
- Субтитр = озвучка: чистый белый текст с обводкой и мягкой тенью (без плашки),
  крупный, pop-in, в нижней-центральной зоне.
- Портрет — заполняет кадр; горизонталь/документ — на размытом фоне.
- Много кадров, быстрая нарезка; финальный кадр — сильный, без призывов.
- Не ставь два почти одинаковых кадра подряд (разные версии одного фото).
- Хронометраж **~25 с** (потолок 30), музыка слышна под голосом.
