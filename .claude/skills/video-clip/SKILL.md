# Короткий ролик (VK Клипы / YouTube Shorts)

Собираешь динамичный вертикальный ролик **до 20 секунд** в стиле популярных
исторических Shorts: **быстрая нарезка** (много кадров, короткие склейки) +
**субтитры, которые проговаривает голос** и появляются с лёгким наездом
(pop-in) в нижней-центральной части экрана. Делаешь **две версии — русскую и
английскую**. Работай автономно.

## Принцип дневника
Целевая дата — сегодня минус 85 лет. Всё в ролике — только то, что известно к
этой дате (правило «без забеганий вперёд»). Фактическая точность критична.

## Модель: строки и кадры — это РАЗНЫЕ дорожки
- **`lines`** — закадровый текст, разбитый на короткие фразы. Каждая фраза
  одновременно **озвучивается и показывается субтитром**. Это смысловая дорожка.
- **`shots`** — визуальный ряд. Кадров **больше, чем фраз** (≈10–13), они
  нарезаются быстро и независимо от границ фраз — отсюда динамика.
Движок сам синхронизирует: озвучивает строки, раскладывает субтитры по времени
речи, а кадры равномерно (с учётом `weight`) заполняют всю длину озвучки.

## Кадрирование (важно)
- **Вертикальное/портретное фото** → заполняет весь кадр с медленным зумом.
- **Горизонтальное/квадратное фото или документ** → показывается **целиком,
  по центру, на собственном красиво размытом и затемнённом фоне** (никаких
  жёстких обрезок и пустых чёрных полей). Субтитр лежит в нижней-центральной
  зоне — туда смотрит глаз, поля сверху/снизу не мешают.

## Процедура

### Шаг 0. Зависимости
```bash
pip install -r requirements.txt -r requirements-video.txt
```

### Шаг 1. Факты и кадры
```bash
python scripts/fetch_sources.py
python scripts/find_photo.py --image-prompt "<запрос>" --category-prompt "<категория>"
```
**Посмотри превью (Read)** и отбери **10–13 сильных архивных кадров** по теме
(их `image_url` из `run/candidates.json`, либо локальные пути из пула). Бери
разные планы: лица, техника, командиры, карта/документ, общий план — это даёт
ритм при быстрой нарезке. Узнаваемый, сильный кадр — в финал.

### Шаг 2. Написать сценарий (RU + EN)
- **6–8 коротких фраз** (`lines`). Зацеп в первой фразе. **Темп быстрый.**
- Каждая фраза — короткая (1 строка, максимум 2), цепляющая, без эмодзи.
- **Не проси подписку и не добавляй призывы** в конце — финал должен бить
  смыслом/эмоцией, а не «подпишись».
- Если в тексте есть цифры/дата, добавь `say` для естественного произношения
  (`text`: «21 июня 1941», `say`: «двадцать первое июня сорок первого»).
- EN — самостоятельная версия, естественная (не дословный перевод).
- Держись **≤20 секунд** суммарной озвучки (голос идёт ускоренно).

### Шаг 3. Записать `run/video_spec.json`
```json
{
  "ru": {
    "lines": [
      {"text": "21 июня 1941.", "say": "Двадцать первое июня сорок первого."},
      {"text": "Последний мирный день перед войной."}
    ],
    "shots": [
      {"image": "run/pool/p_10.jpg", "weight": 1.2},
      {"image_url": "https://…"},
      {"video": "run/footage/clip.mp4", "start": 3.0}
    ]
  },
  "en": { "lines": [...], "shots": [...] }
}
```
`weight` (по желанию) задаёт относительное время кадра на экране (финальный/
сильный кадр можно сделать длиннее). Кадр может быть `image`/`image_url` или
`video`/`video_url` (короткий архивный клип; cover-fit; см. ниже).

### Шаг 3a. Проверить хронометраж (быстро, без рендера)
Синтезируй только `say`/`text` строк и сложи длительности — убедись, что
суммарно **≤20 с**. Если перебор — подрежь фразы.

### Шаг 4. Собрать ролики
```bash
python scripts/make_video.py
```
→ `run/video_ru.mp4`, `run/video_en.mp4` (1080×1920). Голос — edge-tts (за
SSL-прокси сам берёт системный CA-бандл; нет сети → ролик без голоса), музыка —
из `assets/music/` (слышимая пэд-подложка в среднем регистре).
**Проверь результат:** вытащи 4–6 кадров (`ffmpeg -ss <t> -frames:v 1`) и
посмотри (Read) — заполнение/размытие, читаемость субтитров, темп.

### Шаг 5. Публикация
Аплоадеры VK Клипов и YouTube Shorts — отдельно (нужны доступы), см. README.
Русский → VK Клипы, английский → YouTube Shorts.

## Архивное видео (опционально)
Движок умеет вставлять короткие видео-кадры (`{"video": …, "start": s}`).
Источник PD-кинохроники — Internet Archive (например, серия «Why We Fight» —
общественное достояние США). В этом окружении статический ffmpeg **не умеет
seek по сети** (segfault), поэтому фильм нужно скачать целиком (~200 МБ),
просмотреть и нарезать 2–3-секундные фрагменты локально, проверяя историческую
уместность каждого. Делать аккуратно и только при наличии времени.

## Качество
- Кадры — архивные, той эпохи; де-дубликация фото общая (по `pageid`).
- Субтитр = озвучка: короткий, крупный, pop-in, в нижней-центральной зоне.
- Портрет — заполняет кадр; горизонталь/документ — на размытом фоне.
- Много кадров, быстрая нарезка; финальный кадр — сильный, без призывов.
- Хронометраж **≤20 секунд**, музыка слышна под голосом.
