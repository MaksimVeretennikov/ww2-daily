# Короткий ролик (VK Клипы / YouTube Shorts)

Из главного события дня собираешь динамичный вертикальный ролик ~20–35 сек:
несколько архивных кадров, плавный зум, короткий текст на экране и закадровый
голос. Делаешь **две версии — русскую и английскую**. Работай автономно.

## Принцип дневника
Целевая дата — сегодня минус 85 лет. Всё в ролике — только то, что известно к
этой дате (см. правило «без забеганий вперёд»). Фактическая точность критична.

## Процедура

### Шаг 0. Зависимости
```bash
pip install -r requirements.txt -r requirements-video.txt
```

### Шаг 1. Факты и кадры
```bash
python scripts/fetch_sources.py
python scripts/find_photo.py --image-prompt "<запрос>" --category-prompt "<категория>"
```
**Посмотри превью кандидатов (Read)** и отбери **4–6 сильных архивных кадров**,
относящихся к теме (запиши их `image_url` из `run/candidates.json`).

### Шаг 2. Написать сценарий (RU + EN)
Сделай 4–6 «битов». На каждый бит:
- `caption` — **очень короткая** строка на экран (3–6 слов, крупно);
- `narration` — одно произносимое предложение (дикторский текст);
- свой кадр (`image_url`).
Правила сценария:
- **Зацеп в первые секунды** (первый бит — самый сильный факт/вопрос).
- Дальше — развитие; последний бит = вывод + мягкий призыв подписаться.
- Без эмодзи и спецсимволов в озвучке; числа пиши словами для естественного голоса.
- EN — самостоятельная версия (не дословный перевод), естественная.

### Шаг 3. Записать `run/video_spec.json`
```json
{
  "ru": {"segments": [
    {"image_url": "https://…", "caption": "22 июня 1941", "narration": "На рассвете…"},
    {"image_url": "https://…", "caption": "…", "narration": "…"}
  ]},
  "en": {"segments": [
    {"image_url": "https://…", "caption": "June 22, 1941", "narration": "At dawn…"}
  ]}
}
```

### Шаг 4. Собрать ролики
```bash
python scripts/make_video.py
```
Появятся `run/video_ru.mp4` и `run/video_en.mp4` (1080×1920). Голос — edge-tts
(если сеть недоступна, ролик соберётся без голоса), музыка — из `assets/music/`.

### Шаг 5. Публикация
Аплоадеры VK Клипов и YouTube Shorts настраиваются отдельно (нужны их доступы) —
см. README, раздел «Видео». Когда подключены: русский ролик → VK Клипы,
английский → YouTube Shorts.

## Качество
- Кадры — архивные, той эпохи; де-дубликация фото общая (по `pageid`).
- Текст на экране — крупный и короткий; длинные мысли уноси в озвучку.
- Держи общий хронометраж ~20–35 сек (для Shorts/Клипов это оптимально).
