# Короткий ролик (VK Клипы / YouTube Shorts)

Из главного события дня собираешь динамичный вертикальный ролик **до 20 секунд**:
5 архивных кадров, плавное панорамирование, субтитры и закадровый голос.
Делаешь **две версии — русскую и английскую**. Работай автономно.

## Принцип дневника
Целевая дата — сегодня минус 85 лет. Всё в ролике — только то, что известно к
этой дате (см. правило «без забеганий вперёд»). Фактическая точность критична.

## Процедура

### Шаг 0. Зависимости
```bash
pip install -r requirements.txt -r requirements-video.txt
```

### Шаг 1. Факты и кадры
```bash
python scripts/fetch_sources.py
python scripts/find_photo.py --image-prompt "<запрос>" --category-prompt "<категория>"
```
**Посмотри превью кандидатов (Read)** и отбери **5 сильных архивных кадров**,
относящихся к теме (запиши их `image_url` из `run/candidates.json`). Кадр
заполняет вертикаль целиком (cover-crop + панорама), поэтому **горизонтальные
фото тоже годятся** — пустых полей не будет. Сильный, узнаваемый кадр — в финал.

### Шаг 2. Написать сценарий (RU + EN)
**5 битов.** На каждый бит:
- `text` — строка, которая **и показывается субтитром, и проговаривается
  голосом** (это одно и то же — субтитры синхронны озвучке);
- свой кадр (`image` — локальный путь или `image_url`);
- по желанию `say` — отдельный текст для синтеза, если в `text` есть цифры
  (например, `text` = «21 июня 1941», `say` = «двадцать первое июня сорок
  первого») для естественного произношения.
Правила сценария:
- **Зацеп в первом бите** (самый сильный факт/вопрос), последний бит = вывод +
  короткий призыв подписаться («Подпишись» / «Follow»).
- Фразы **короткие** (укладываются в 2 строки субтитра) и цепляющие.
- Без эмодзи и спецсимволов в озвучке.
- EN — самостоятельная версия (не дословный перевод), естественная.
- Держись **≤20 секунд суммарно** (для Shorts/Клипов это оптимально). Озвучка
  идёт чуть бодрее (rate), но 5 коротких фраз — это ~18–20 с.

### Шаг 3. Записать `run/video_spec.json`
```json
{
  "ru": {"segments": [
    {"image": "run/pool/p_10.jpg", "text": "21 июня 1941. Последняя мирная ночь.",
     "say": "Двадцать первое июня сорок первого. Последняя мирная ночь."},
    {"image_url": "https://…", "text": "Три группы армий готовы к броску."}
  ]},
  "en": {"segments": [
    {"image": "run/pool/p_10.jpg", "text": "June 21, 1941. The last night of peace.",
     "say": "June twenty-first, nineteen forty-one. The last night of peace."}
  ]}
}
```

### Шаг 3a. Проверить хронометраж (без рендера видео — это быстро)
Прежде чем рендерить (рендер минуты), синтезируй только `say`-строки и сложи
длительности, чтобы гарантировать **≤20 с**. Если перебор — подрежь фразы.

### Шаг 4. Собрать ролики
```bash
python scripts/make_video.py
```
Появятся `run/video_ru.mp4` и `run/video_en.mp4` (1080×1920). Голос — edge-tts
(за SSL-прокси сам берёт системный CA-бандл; если сеть недоступна, ролик
соберётся без голоса), музыка — из `assets/music/` (слышимая пэд-подложка).
**Проверь результат:** вытащи 4–5 кадров через ffmpeg (`-ss <t> -frames:v 1`) и
посмотри (Read) — заполнение кадра, читаемость субтитров, отсутствие полей.

### Шаг 5. Публикация
Аплоадеры VK Клипов и YouTube Shorts настраиваются отдельно (нужны их доступы) —
см. README, раздел «Видео». Когда подключены: русский ролик → VK Клипы,
английский → YouTube Shorts.

## Качество
- Кадры — архивные, той эпохи; де-дубликация фото общая (по `pageid`).
- Субтитр = озвучка, крупный и короткий (2 строки), по нижней трети на градиенте.
- Кадр заполняет вертикаль целиком, плавная панорама; финальный кадр — сильный.
- Хронометраж **≤20 секунд**, музыка слышна под голосом.
