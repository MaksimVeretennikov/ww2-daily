# Рубрика «Оружие / Техника»

Один образец техники или оружия, связанный с событиями этих дней 85 лет назад:
узнаваемый, с понятной аудитории историей. Работай автономно.

## Процедура

### Шаг 0. Подготовка
```bash
pip install -r requirements.txt
```

### Шаг 1. Собрать факты
```bash
python scripts/fetch_sources.py
```
Прочитай `run/facts.json`: `date`, `combined` (события), `featured` →
`featured.weapon` (что **уже показывали — не повторяй**), `recent_posts`.

### Шаг 2. Выбрать технику и написать пост
Выбери **узнаваемый** образец (танк/самолёт/корабль/орудие), связанный с боями
этих дней и отсутствующий в `featured.weapon`. Напиши:
- `post`: имя жирным (`<b>Т-34</b>`), пустая строка, чем важен **в эти дни**,
  1–2 надёжные характеристики/цифры, роль в событиях, живая деталь. ~700–850
  знаков. Без эмодзи, CAPS, ссылок. Заверши строкой-резюме.
- `photo_caption` — подпись к фото, до ~150 знаков.
- `image_prompt` / `category_prompt` — название на английском + год
  (напр. `T-34 tank 1941`); категория — каноничное имя модели.

### Шаг 3. Фото
```bash
python scripts/find_photo.py --image-prompt "<image_prompt>" --category-prompt "<category_prompt>"
```
**Посмотри превью (Read)**, выбери архивный кадр именно этой техники; нет —
расширь запрос (1–2 повтора) или `image_index: -1`.

### Шаг 4. Опубликовать
`run/draft.json`:
```json
{ "kind": "weapon", "subject": "Т-34", "ww2_date": "<facts.date.iso>",
  "topic": "<кратко по-английски>", "image_index": 0,
  "telegram_caption": "<i>{photo_caption}</i>\n\n<b>{название}</b>\n\n{post}…",
  "post_x": "<= 260, английский, та же тема, с даты (June D, 1941 —); без ссылок/эмодзи>" }
```
Длину ≤ 1024. Затем `python scripts/publish.py`.

### Шаг 5. Сохранить память
```bash
git add state/history.json docs/ && git commit -m "rubric/weapon: {subject}" && git push origin HEAD:main
```

## Правила
- **Никаких служебных дисклеймеров:** не добавляй приписку про Бундесархив /
  Немецкий федеральный архив и «оригинальные подписи, которые могут быть
  ошибочными». Увидишь её в старых постах — не копируй, формат устарел.
- **Без забеганий вперёд (дневник во времени):** бери только образцы и
  модификации, существующие к целевой дате. Пример: в 1941 — Т-34 обр. 1940/1941,
  но **не** Т-34-85 (1944). Не упоминай поздние модификации и итоги войны.
- `subject` — точное название модели (по нему антиповтор). Не повторяй `featured.weapon`.
- Если `publish.py` пишет, что техника за сегодня уже была — НЕ форсируй, заверши.
- Бери узнаваемые образцы; точность ТТХ важнее эффектности.
