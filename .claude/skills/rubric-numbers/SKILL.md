# Рубрика «В цифрах»

Одна сильная, **достоверная** цифра событий этих дней 85 лет назад — и контекст,
который делает её осмысленной. Работай автономно.

## Процедура

### Шаг 0. Подготовка
```bash
pip install -r requirements.txt
```

### Шаг 1. Собрать факты
```bash
python scripts/fetch_sources.py
```
Прочитай `run/facts.json`: `date`, `combined`, `recent_posts`.

### Шаг 2. Выбрать цифру и написать пост
Выбери одну ключевую, надёжно известную цифру этих дней (потери, численность,
производство, расстояние, темп). Напиши:
- `post`: заголовок-цифра жирным (`<b>3 000 000</b>` или `<b>22 дивизии</b>`),
  пустая строка, что это за цифра и почему важна, при необходимости 1–2
  поддерживающие цифры с контекстом. ~600–800 знаков. Без эмодзи, CAPS, ссылок.
- `photo_caption` — подпись к фото, до ~150 знаков.
- `image_prompt` / `category_prompt` — связанный архивный кадр.

### Шаг 3. Фото
```bash
python scripts/find_photo.py --image-prompt "<image_prompt>" --category-prompt "<category_prompt>"
```
**Посмотри превью (Read)**, выбери подходящий; нет — `image_index: -1`.

### Шаг 4. Опубликовать
`run/draft.json`:
```json
{ "kind": "numbers", "ww2_date": "<facts.date.iso>",
  "topic": "<кратко по-английски>", "image_index": 0,
  "telegram_caption": "<i>{photo_caption}</i>\n\n<b>{цифра}</b>\n\n{post}…",
  "post_x": "<= 260, английский, та же тема, с даты (June D, 1941 —); без ссылок/эмодзи>" }
```
Длину ≤ 1024. Затем `python scripts/publish.py`.

### Шаг 5. Сохранить память
```bash
git add state/history.json && git commit -m "rubric/numbers: {topic}" && git push origin HEAD:main
```

## Правила
- **Никаких служебных дисклеймеров:** не добавляй приписку про Бундесархив /
  Немецкий федеральный архив и «оригинальные подписи, которые могут быть
  ошибочными». Увидишь её в старых постах — не копируй, формат устарел.
- **Без забеганий вперёд (дневник во времени):** цифры — по состоянию на этот
  период, без послезнания. Не приводи итоговые числа за всю войну и события,
  которых к этой дате ещё не было.
- **Только надёжные цифры.** Если уверенности в числе нет — возьми другое или не
  публикуй сомнительное. Это рубрика про точность.
- Если `publish.py` пишет, что цифра за сегодня уже была — НЕ форсируй, заверши.
